# Code style backend & frontend

Activation: **Glob** — `backend/**` và `frontend/**`.

Nguồn duy nhất của rule này, đọc file tương ứng, đừng đoán:

- Sửa file trong `backend/` → @/backend/CLAUDE.md
- Sửa file trong `frontend/` → @/frontend/CLAUDE.md

Hai file đó chỉ nói *viết code thế nào*. Chọn công nghệ, cấm cài gì → `docs/STACK.md`.
ERD + API surface → `docs/ARCHITECTURE.md`. Token màu/chữ + responsive → `docs/DESIGN_SYSTEM.md`.
Không fork nội dung sang `.agents/`.
