## Kết quả
`docs/lane-c-map.html` — một file tĩnh, tự chứa, dùng lại đúng ngôn ngữ thị giác của
`product-flow-map.html` (cùng bộ token màu, cùng kiểu zone/node/panel). Bốn tab:

1. **Việc đã làm** — 7 issue được giao + 3 việc ngoài issue, nhóm theo bước của đề. Mỗi ô mở ra
   panel: bám vào mục nào của đề, làm gì, vì sao, quyết định thiết kế, techstack, file.
2. **Luồng dữ liệu** — năm tầng nối bằng mũi tên: trình duyệt → TanStack Query → proxy của Next →
   `analytics/` chỉ đọc → Postgres. Tách riêng `CardLinkModule` là **ngoại lệ ghi duy nhất**.
3. **Sáng tạo UI/UX** — 12 thay đổi, mỗi cái có khối *trước / sau / vì sao*. Chia ba nhóm: chuyển
   động mang thông tin · hình mang thông tin · tiếp cận được.
4. **Techstack** — 12 mục, mỗi mục nói nó làm gì **ở đây**, chọn vì sao, và đã loại cái gì.

Điểm khác `product-flow-map.html`: file kia trả lời *"sản phẩm chạy thế nào"*, file này trả lời
*"làn C đã thêm gì, vì sao làm thế, và dựng bằng gì"*. Không vẽ cạnh SVG — tab luồng dùng chuỗi
zone nối bằng mũi tên, không cần tính hình học.

Ghi cả những chỗ **đã vấp**: lockfile npm 11 vs npm 10, class Tailwind sinh động không được biên
dịch, `tsx` không phát metadata cho DI, icon lucide render `<circle>` làm test bắt nhầm.

Theo yêu cầu tiếp theo, file **mô tả bản cài đặt sau cùng**: bỏ hết chú thích trạng thái (số hiệu
PR, "đã merge", "chờ batch"). Phụ đề mỗi ô đổi từ số PR sang **đường dẫn màn hình** — hữu ích hơn
khi đọc, và không cũ đi sau mỗi lần merge. Giữ lại hai nhãn mang nội dung sản phẩm: "điểm nhấn
demo" và "không phải human validation".

Kiểm bằng Playwright thật trên Chromium: mở file, đổi cả 4 tab, click node ở từng tab, panel hiện
đúng, và khẳng định **không còn chuỗi `PR #<số>` / "đã merge" / "chờ batch"** ở tab nào — 0 lỗi
console. README và `handover.md` thêm dòng trỏ tới file.
